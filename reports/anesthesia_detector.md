# Anesthesia note detector

Generated by `src/anesthesia_detector.py`.

TF-IDF + logistic regression, trained to predict whether a note has an "ANESTHESIA:" heading **with every anesthesia heading line removed from the text**, so it has to learn from the rest of the note. Scores are out-of-fold (5-fold cross-validation), threshold 0.5.

| Metric | Value |
|---|---:|
| Precision | 0.66 |
| Recall | 0.93 |
| F1 | 0.77 |
| ROC-AUC | 0.940 |

**Precision is a lower bound.** The training label ("has a heading") misses notes that describe anesthesia without one. Of the 294 notes the detector flags that have no heading, 85% mention anesthesia, sedation or intubation somewhere in the text (some only in passing, such as "anesthetic risks were discussed"). Many of these "false positives" are real operative notes.
